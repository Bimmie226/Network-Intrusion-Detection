# Network Intrusion Detection 

## Cấu trúc

| Đường dẫn | Mục đích |
|---|---|
| `data/raw/` | Dataset gốc |
| `data/processed/` | Dữ liệu sau xử lý |
| `notebooks/` | Notebook khảo sát và thử nghiệm |
| `src/data_loader.py` | Đọc dữ liệu |
| `src/preprocessing.py` | Mã hóa, chuẩn hóa và chia dữ liệu |
| `src/models/` | Các thuật toán phát hiện |
| `src/train.py` | Huấn luyện, chọn tham số trên validation |
| `src/evaluate.py` | Đánh giá tổng thể và known/novel attacks |
| `src/visualization.py` | Vẽ biểu đồ |
| `outputs/figures/` | Biểu đồ sinh ra |
| `outputs/metrics/` | Bảng chỉ số đánh giá |
| `artifacts/` | Mô hình và bộ tiền xử lý đã lưu |
| `reports/` | Báo cáo và slide |
| `main.py` | Điểm bắt đầu của chương trình |
